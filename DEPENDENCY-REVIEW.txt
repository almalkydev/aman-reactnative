Remaining transitive mobile toolchain advisories:
- braces <=3.0.3 (GHSA-vfj7-8cjw-p6xm), high, no patched version available.
  Used by build-time globbing (Tailwind/Metro/Jest tooling), not report payloads.
  Only trusted repository file patterns are processed. Do not build untrusted
  configuration. Runtime report fields never reach a glob compiler.
- node-forge <=1.4.0 (GHSA-86w9-cpqp-85rv), high, no patched version available.
  Used by Expo development/code-signing tooling. Aman uses no signed OTA update
  service, and server JWT verification uses jsonwebtoken/Node crypto instead.
  Review again before adding Expo signed updates.
- image-size <=2.0.2 (GHSA-5p2g-fcmc-qvqq / GHSA-w3rx-r6r6-pgpr), high.
  Metro's SDK 54 interface depends on the v1 filesystem API; the patched v2 API
  breaks native asset bundling. Retain Expo's supported dependency until migration.
  Only checked-in/trusted image assets go through Metro. Uploaded report photos
  go to Express storage, not image-size. Never build untrusted image assets.
- uuid <11.1.1 (GHSA-w5hq-g745-h8pq), moderate.
  Expo/xcode tooling dependency; no app calls v3/v5/v6 with caller buffers.
  Report IDs use expo-crypto.randomUUID, server IDs use Node crypto.randomUUID.

The audit also reports ancestor packages affected through these dependencies.
These warnings remain; they are not suppressed or claimed fixed. Forced major
upgrades were not applied. The intended mitigation is restricting build inputs
and keeping Metro local until a tested supported-SDK migration is performed.
